This optional data archive is for the generated-furigana feature on `feat-furigana-support`. It contains UTF-8 IPADIC dictionary files, the dictionary notices, and a version/schema/file-checksum manifest. It contains no component binary or installer.

Generation is disabled by default. The component downloads this archive only when the user chooses **Download dictionary and enable** in OpenLyrics → Furigana preferences. Embedded kana metadata works without this download. Generated readings are dictionary estimates and may differ from the singing.
